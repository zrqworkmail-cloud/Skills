# 调研与模板检查

## 定向调研

调研服务于当前任务，不以安装数量或搜索数量作为成果。围绕模板继承、可编辑性、中文显示与验收能力比较候选路线。

1. 先盘点已有技能、渲染器、字体和插件。优先复用已验证的本地工具。
2. 按需要搜索 GitHub、官方文档、CSDN、博客园、作者博客、YouTube、X 等渠道。不要求每次搜索覆盖全部平台。
3. 社区教程作为线索，用原仓库和官方文档确认实际能力；未观看视频、访问失败或只看摘要时注明，不能假称核验。
4. 查清输出到底是原生对象、SVG 转换、整页位图还是 HTML。导出 PPTX 不能证明每个对象可编辑。
5. 比较许可、维护、依赖、兼容性、费用与上传范围。热度只是辅助信息，日期与版本需记录，不宣称永久“最好”。
6. 下载或安装前静态检查技能入口和脚本；不得因下载了入口就执行其中任意指令。仅引入当前任务确有收益的工具，说明实际安装项。

简短记录：来源链接、核验日期/版本、支持能力、未验证限制、本轮采用与否。现有记录仍适用时可复用，但新工具的能力变化要刷新核查。

## 参考线索，不是已安装依赖

以下仓库仅用于发现制作路线，使用时核查当前源码、许可和能力：

- [ppt-master](https://github.com/hugohe3/ppt-master)：模板编辑和多种演示生成路线的候选。
- [codex-ppt-skill](https://github.com/ningzimu/codex-ppt-skill)：整页图片路线的候选；不要把图片式 PPTX 当成原生可编辑交付。
- [presentation-skill-codex](https://github.com/JohnTan38/presentation-skill-codex)：结构化规划、构建与 QA 的候选。
- [pptx-notes-editor](https://github.com/cm8421/pptx-notes-editor)：演讲备注与关系映射的参考线索。

这些链接不构成维护状态、质量排名或本技能授权捆绑其代码的保证。本包不包含第三方技能源码。

## 模板检查表

| 检查 | 记录内容 |
| --- | --- |
| 几何 | 画布宽高、比例、标题区和正文区、页边距 |
| 视觉 | 主色、辅助色、强调色、明暗背景、边界线 |
| 字体 | 主题字体与直接字体、东亚字体、字号、粗细 |
| 身份 | 徽标、校名、组织名、页眉页脚；不得擅改 |
| 结构 | 母版/布局、占位符、章节页、封面和结尾 |
| 动态内容 | 日期、页号字段；软件重算可能覆盖缓存文本 |
| 内容对象 | 文字、表格、原生图表、图片与不可编辑区域 |
| 输出风险 | 字体缺失、替代字体、复杂效果、外部关系 |

使用当前环境可用的演示运行库。若宿主提供工作区依赖加载接口，先调用确认；没有接口时检查本地依赖，不能假称加载成功。
涉及 python-pptx 或 PptxGenJS 的 API 时，核对已安装版本和官方文档，不依赖未经核实的代码片段。

## 规划交接

记录交付模式、听众、时长、正文/附录、模板哈希、样页候选、数据来源与待确认限制。个人文件路径只保留在本地项目记录，不进入可分享的技能包。
学术结论与制作工具经验分开；不得用工具宣传为研究结果提供依据。

## 按需制作规划

正式整套或复杂修改前，按工作量制作简明逐页规划：页码/标题、要回答的问题、核心结论、证据来源、可用图表或图片、版式和阅读风险。结合素材纵横比决定直接呈现、拆分或局部放大；来源模糊或图像不清晰时标记待核实。简单单页和小修可省略完整表格。

从模板中归纳封面、总览、正文、结果和结论等可复用版式；内容需要时选择变体，不为每页强制加装饰图或套同一布局。按用户要求选择样页数量，默认一张代表页；模板实际画幅和风格优先于外部模板的固定设置。
