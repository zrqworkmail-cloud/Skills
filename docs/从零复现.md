# 从零复现：在另一台机器上搭起制作流

**结论先行：clone 本仓不能直接开始生产视频。** 本仓交付的是流程规范与
参考实现，不含运行时、模型、字体、工作流模板与平台凭据。按下列清单准备后，
分路线可达性见文末。

## 1. 必备运行时（全部自带安装，本仓不提供）

| 依赖 | 用途 | 验证命令 |
|---|---|---|
| Python 3.10+ | 测量、混音、合成脚本 | `python --version` |
| Node.js 18+ | Remotion 渲染、Puppeteer 截图 | `node --version` |
| ffmpeg / ffprobe | 编码、探测、混流 | `ffmpeg -version` |
| Chrome 或 Chromium | Puppeteer 无头渲染 | 设置 `CHROME_PATH` 或让 Puppeteer 用自带 Chromium |
| 中文字体 | 画面文字 | 安装 Noto Sans SC / Noto Serif SC（SIL OFL 1.1）等 |

Python 依赖见各包 `requirements.txt`；Node 依赖见
`video-generator/workbuddy-video-generator/reference/remotion/package.json`
（`npm install`）。环境变量样例见各包 `.env.example`。

**外部二进制一律支持环境变量覆盖，脚本内不写死绝对路径**：
`FFMPEG` / `FFPROBE` / `FFMPEG_PATH`、`PY`、`CHROME_PATH`、
`COMFY_OUTPUT_DIR`、`COMFY_WORKFLOW_TEMPLATE`。修改后请在目标环境实际
执行一次上述验证命令，不要只看"文件存在"。

## 2. 代码渲染路线（Remotion + Puppeteer）

```bash
cd <你的项目目录>
npm install                      # 依据 reference/remotion/package.json
export CHROME_PATH=/path/to/chrome   # 可选；不设则用 Puppeteer 自带 Chromium
export FFMPEG_PATH=ffmpeg
python -c "import numpy, PIL; print('ok')"
```

`reference/scripts/` 与 `reference/src/` 是**参考实现**：需要按你的项目结构
接线，不是可直接执行的安装器。`scripts/env_report.sh`（qoder 包）是只读
能力探针，先跑它确认哪些阶段可用。

## 3. AI 生成路线（ComfyUI / Wan2.2 / TTS）

以下条件缺一不可，且**都不在本仓内**：

1. 本机部署 ComfyUI 并监听 `127.0.0.1:8188`；
2. 下载 Wan2.2 I2V FP8 HIGH/LOW、umt5_xxl、Wan2.1 VAE 等权重（数十 GB）；
3. 在 ComfyUI 里搭好 Wan2.2 四步 Lightning 工作流，**导出 API 格式 JSON**
   （ComfyUI → 保存 API 格式），命名为 `workflow.api.json`，
   或用 `COMFY_WORKFLOW_TEMPLATE` 指向它；
4. 如需 TTS，下载 Kokoro `kokoro-v1.0.onnx` 与 `voices-v1.0.bin`，
   配置到脚本读取的目录，并安装 `kokoro-onnx`；
5. 具备可用 GPU；多实例抢同一端口时需自行做队列/门控。

模型与工作流绑定具体节点版本，本仓不提供可直接用的 `workflow.api.json`
样例——提供一个跑不通的模板比不提供更有害。

| 能力 | 是否随仓提供 |

环境重新核实**。

## 5. BGM（自备音轨）

**本仓不分发任何 BGM 音频文件**——原随仓母版因来源与授权无法确认已移除。
下载后须自备授权明确的音轨，用 `VIBE_BGM`（旧脚本兼容 `VIBE_BGM_SRC`）指向，
或放到 `assets/audio/`、功能层 `video-generator/assets/audio/`。
完整指引见 [video-generator/assets/audio/README.md](../video-generator/assets/audio/README.md)。

自备音轨的版权与商用授权由使用者自行负责。功能层目录已加 `.gitignore`
排除常见音频格式，避免把自备音轨误提交进仓库。

## 6. 路线可达性

## 7. 安全提示

`reference/scripts/sync_workflow.py` 是来源仓的自动同步脚本，**不要照搬其
定时任务配置**。本仓版本默认只暂存白名单目录并拦截疑似凭据文件；仍需
`--all` 时才全量暂存。任何自动推送都应先跑 `--dry-run`。
