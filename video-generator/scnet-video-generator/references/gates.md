# 四道门禁

> 门禁不是流程装饰。它的作用是把缺陷挡在更便宜的环节。

| 门禁 | 位置 | 挡住什么 | 返工成本对比 |
|---|---|---|---|
| G1 时长闭合 | 立项结束 | 时长失控、文案超载 | 1× |
| G2 分镜审批 | 设计结束 | 构图、景别、安全区返工 | 10× |
| G3 时间轴闭合 | 制作结束 | 空洞、重叠、总长错位 | 10× |
| G4 交付验收 | 交付结束 | 规格错、偏色、音画不同步 | 50× |

---

## G1 时长闭合

**输入**：`script.md`、`audio-manifest.json`

- [ ] 每句文案有明确的 `[startFrame, endFrame]`
- [ ] `Σ 镜头帧 + 尾帧 = durationInFrames`，全为整数
- [ ] 尾帧留 6–12 帧
- [ ] 配音总时长与总帧数一致（误差 ≤2 帧）
- [ ] 快读测试：按 5 字/秒念一遍，不超时

**放行条件**：以上全绿，且导演/负责人确认文案定稿。

**失败处理**：删句优先于加速。加速念白会牺牲可读性。

---

## G2 分镜审批（最关键）

**输入**：`shotlist.json`、逐镜静帧、color script

- [ ] 每镜有静帧，且是最终构图的近似（不是占位色块）
- [ ] 六要素齐全：景别 / 角度 / 运镜 / 构图 / 时长 / 声音
- [ ] 每镜至少一个新信息
- [ ] 相邻镜头景别有变化
- [ ] 文字区在安全区内，最长文案不溢出
- [ ] 主体运动方向跨镜一致
- [ ] 色彩走向与 color script 一致
- [ ] 缩到 320px 宽，标题仍可读（封面可用）

**放行条件**：逐镜签字，无「待定」。

**失败处理**：回到 B1 重排镜头，不要带着问题进入实现——实现阶段改构图等于重写组件。

---

## G3 时间轴闭合

**输入**：`timeline.json`

```bash
node scripts/check-timeline.mjs src/data/timeline.json
```

- [ ] 脚本退出码为 0
- [ ] 镜头 id 唯一
- [ ] 每镜 `frames` 为正整数
- [ ] `from` 连续（若显式声明）
- [ ] 转场帧已计入总长
- [ ] 平均镜头长度在片型目标区间
- [ ] 每镜组件可独立播放

**放行条件**：脚本 PASS + 单镜抽播无异常。

**失败处理**：补帧或删镜，不要靠拉伸单镜掩盖节奏问题。

---

## G4 交付验收

**输入**：成片、`render-args.txt`、QA 记录

**技术项**

- [ ] `ffprobe`：分辨率、帧率、像素格式、时长与设计一致
- [ ] 像素格式为标准 `yuv420p`（透明片除外）
- [ ] 同帧两次渲染哈希一致
- [ ] 首帧不是黑场（除非设计如此）

**内容项**

- [ ] 全量文案导出通读，无错别字
- [ ] 字幕与配音逐句对齐（误差 ≤1 帧）
- [ ] 逐镜检查首帧 / 中帧 / 末帧
- [ ] 正文对比度 ≥ 4.5:1

**声音项**

- [ ] 响度 −14 LUFS（网络）或 −23 LUFS（广播），±1 LU
- [ ] 真峰 ≤ −1.5 dBTP
- [ ] 手机外放人声可懂
- [ ] 无人声段配乐不突兀

**交付项**

- [ ] 命名符合 `{campaign}/{variant}-{w}x{h}-{yyyymmdd}.mp4`
- [ ] 附渲染参数快照
- [ ] 附可编辑中间产物
- [ ] 源码打 tag，依赖锁定

## 失败模式库

| 失败模式 | 症状 | 防线 |
|---|---|---|
| 无分镜直接开工 | 反复改构图 | G2 |
| 无镜头库 | 每镜从零调参，风格漂移 | 配方卡 |
| 声音后配 | 全片重排节奏 | A3 |
| 无逐帧 QA | 错帧、闪白、字幕截断 | G4 |
| 硬编码文案 | 改一句要动代码 | props 契约 |
| 版本浮动 | 三个月后渲染结果不同 | 精确锁版本 + 哈希校验 |
| 只交 MP4 | 客户改一个字就重做 | 可编辑中间产物 |
| 门禁走过场 | 签字了但没看图 | 静帧必须是人眼确认过的成品构图 |
