# 高频错误速查（症状 → 根因 → 修法）

> 主干见 `../SKILL.md` 阶段五。这张表是"出问题了先查这里"的索引，不是开工清单——开工前该读的是 `design-checklist.md` 与 `retro-lessons.md`。

| 症状 | 根因 | 修法 |
|---|---|---|
| 公开仓 clone 下来脚本直接报"找不到文件" | 脚本写死了外部二进制的本机绝对路径（ffmpeg/ffprobe/浏览器），那台机器上已失效 | 走"环境变量 → 库自带 → PATH"三级解析；核验要在目标环境实际执行一次 |
| 清理完本轮 diff，历史脚本里还留着死路径 | 只扫本轮改动的文件，没动的旧脚本没人跑也没人看 | 公开前扫全仓（含未改动的历史文件），命中即处理 |
| 开头 3 秒留不住人 | 先铺垫再给结论 | 结论前置，第 0 帧给反直觉 |
| 字幕压画面主体 | 逐镜手摆，没有统一安全区 | 统一组件 + 主体 y<780 |
| 长句末尾两三个字单独成行 | 字数×字号 > 容器宽，超了不报错只折行 | 降一级字号或拆句 |
| 文字压亮部看不清，自动判据全过 | 对比度不在任何判据里 | 排版前看背景亮度，亮区加底衬 |
| 器物/服饰/建筑形制画错，被一眼指出 | 按"大概长这样"落笔，没找实物参考 | 先搜馆藏实物图、按形制拆结构再简化；地图先列方位坐标表 |
| 加一堆小动效，静止判据只降 2% | 判据算全画面平均差，小元素贡献极小 | 用大面积/高对比；或改镜头长度 |
| 柔光呼吸加了没效果 | 下采样后软过渡被抹平，是伪运动 | 用画面实体的硬边动作 |
| 静态图表/文字型版面读出"整镜 100% 静止" | 逐帧差只有阈值的 1/10，判据对这类画面不敏感 | 缩短镜头或改结构，别加全局推拉/扫描线 |
| 数字滚完了，画面里的事件还没发生 | 计数动画独立走时间轴 | 由视觉事件反推进度；卡整秒用硬标定帧常量 |
| 相邻两镜主体状态跳变 | 后一镜另起一套初始值 | 从前一镜末态接续（相机/缩放/明暗往下传） |
| 比例隐喻被读成算法机制图 | 连线与标签暗示了并不存在的结构 | 写清单位与分母、标签用描述词、删掉暗示机制的连线 |
| 抽公共组件后旧镜头渲染结果悄悄变了 | 重构改了隐含参数（间距/基线/描边） | 同一帧号逐像素比对，max diff = 0 |
| 切镜处主体突然消失/跳变 | 后一镜首帧没补回前一镜末态的元素 | 切点前后两帧比对，共享区域差异只剩抗锯齿边 |
| 一片区域里的点全挤在一侧 | 随机取样没有空间均匀性 | 按方位角等距取样；尺寸按投影深度做近大远小 |
| 光晕边缘出现竖线或"框" | `radial-gradient` 在容器边界未衰减到 0 | 容器放大到内容区外，或改 `text-shadow`/`box-shadow` |
| 光斑边缘露出一圈方形边界 | `radial-gradient` 默认按 `farthest-corner` 铺满，容器非正方形时边角 alpha 降不到 0 | 显式写 `closest-side` 让渐变在最近边收尾 |
| 观众看到"1.4T token"就划走 | 量化名词单独上屏，没有白话释义也没有可感锚点 | 同屏给释义 + 可感锚点（"1 token ≈ 0.75 个英文词"） |
| 补一段对比数据把口播挤爆了 | 补充内容直接插进口播正文 | 补充内容写成括号旁注或附录，不占口播配时 |
| 内容讲完了，镜头还在空转几秒 | 镜头时长按拍数凑 | 时长跟内容长度走：讲完就切 |
| 17s 镜头怎么加动效都闷 | 镜头太长 + 素材静态 | >12s 必须配持续事件，或缩短 |
| 循环 BGM 接点"断一下" | 硬接母版，尾淡出后突然满音量 | 延长剪辑或等功率环 |
| 接点仍"塌一下" | 交叉淡化用线性权重，中点掉 3dB | 等功率曲线 |
| 加了音效后成片削波 | 只验 BGM 电平 | 混完重新过电平判据 |
| 封面上的字与底图上的字叠在一起 | 底图从成片抽帧 | 只从素材层抽 |
| 发布后被判非原创/限流 | AI 画面只勾"原创"没标 AI | 按平台要求标注 |
| 填好的表单突然全丢 | 脚本进程退出，浏览器一起关 | 让进程常驻 |
| 数据看着很差但刚发布 | 冷启动前 30 分钟波动极大 | 等 2 小时看 2 秒跳出率 |
| 新 clone 的仓库首次提交报 `unable to auto-detect email address` | 新克隆不继承全局 git 身份 | 先 `git config user.name/email` 再提交 |
| 在 GitHub 网页建目录，多出一个平铺的怪文件 | 文件名里的 `/` 没生效 | 用「Create new file」输入 `目录/文件名`，建完确认层级 |
