# 讲稿 · 《Llama 4 MoE：不激活全部参数，也能扩大容量》

## Shot 01｜0:00–0:10
一个拥有 4000 亿参数的模型，为什么每次处理 Token 时，只需要激活约 170 亿参数？
（停 1 秒，让 400B / 17B 的对比立住）

## Shot 02｜0:10–0:20
这不是简单的模型压缩，而是一种完全不同的参数使用方式。
它就是 Llama 4 Maverick 采用的混合专家架构，MoE。

## Shot 03｜0:20–0:28
2023 年，Meta 发布初代 LLaMA，用更小的模型和更多数据，推动了开放权重生态。
（右上角 backronym 标签 `LLaMA = Large Language Model Meta AI` 淡入——**只看不念**）

## Shot 04｜0:28–0:38
2024 年，Llama 3.1 把稠密 Transformer 推到 4050 亿参数，每个 Token 都要过全部参数。

## Shot 05｜0:38–0:48
但模型越大，计算和部署成本越高；405B 的推理成本随参数线性上涨，很快撞上成本墙。

## Shot 06｜0:48–0:58
MoE 不是新发明：1991 年就有，但每个专家都要算；2017 年稀疏门控只激活少数，才真正省算力。
（1991 卡：4 个专家全亮；2017 卡：只亮 1 个。这一镜是全片「考古」的唯一一拍，别展开成历史课。）

## Shot 07｜0:58–1:08
2025 年，Meta 换了思路：不再让所有参数始终参与计算，而是根据输入动态选择。

## Shot 08｜1:08–1:18
传统 Transformer 里，每个 Token 都要通过同一层相同的前馈网络，也就是 FFN。

## Shot 09｜1:18–1:28
MoE 把这个 FFN 拆成多个拥有独立参数的专家网络，模型容量可以做得很大。

## Shot 10｜1:28–1:38
但关键在于，并不是每次都运行所有专家；模型只执行被 Router 选中的那一部分。

## Shot 11｜1:38–1:48
Router 根据 Token 当前的隐藏状态，通过一个可学习的矩阵，给每个专家打分。

## Shot 12｜1:48–1:58
Llama 4 Maverick 用 Top-1 路由：一层有 128 个路由专家，但每个 Token 只选 1 个。

## Shot 13｜1:58–2:08
这个选择不是人工设定的关键词规则，而是训练出来的路由参数和上下文表示共同决定的。

## Shot 14｜2:08–2:18
除了 128 个路由专家，Maverick 还有 1 个共享专家；它不经过 Router，每个 Token 都会用。

## Shot 15｜2:18–2:28
所以一个 Token 实际走两条路径：一条是共享专家，另一条是 Router 选中的路由专家。

## Shot 16｜2:28–2:38
路由分数经过 Sigmoid 得到门控系数，乘在专家输出上，再把两条路径的结果相加。

## Shot 17｜2:38–2:48
这让容量很大，但 17B 激活不等于 17B 存储：没有参与计算的专家权重，仍然要占显存。

## Shot 18｜2:48–2:58
如果专家分布在不同 GPU 上，还要处理跨卡通信、负载均衡和 Token 调度，成本没有消失。

## Shot 19｜2:58–3:10
2026 年 Meta 转向 Muse，但问题没变：参数可以很多，不必全部激活。剩下的开放问题是——加多少专家、激活几个、怎么排层。

## 附：可能被问到的问题

| 问题 | 一句话回答 |
| --- | --- |
| 为什么是 400B / 17B？ | 这是 Llama 4 Maverick：400B 总参数、17B 激活参数；Scout 是 109B 总 / 17B 激活 / 16 专家。 |
| MoE 是哪年提出的？ | 1991 年 Jacobs / Jordan / Nowlan / Hinton《Adaptive Mixtures of Local Experts》。但当年是 dense MoE（每个专家对每个输入都算），真正「省算力」是 2017 年 Shazeer《Outrageously Large Neural Networks》的稀疏门控（top-k）。 |
| Llama 这个名字哪来的？谁起的？ | 是 **backronym**：先有动物名 Llama，再倒着凑出「Large Language Model Meta AI」。**具体由谁命名，公开资料没有明确记录——不编。** |
| Llama 背后的公司 / 老板？ | Meta（Meta AI / FAIR），CEO 是 Mark Zuckerberg，首席 AI 科学家是 Yann LeCun。 |
| Top-1 和 Top-8 有什么区别？ | Top-1 每个 Token 只选 1 个路由专家，路由简单、激活低；Top-8（DeepSeek-V3、GLM-5.2）会组合 8 个专家，表达能力强但调度复杂。 |
| 共享专家是必须的吗？ | 不是。Llama 4、DeepSeek-V3、Qwen3.8、GLM-5.2 有共享专家；Mixtral、DBRX、gpt-oss 公开资料未见。共享专家用来兜住通用知识。 |
| 为什么公式里 g_j(x) 乘在 E_j(x) 上？ | 门控系数是对专家**输出**的加权；专家输入仍然是 x。写成 E_j(gx) 会误解成先缩放输入。 |
| 17B 激活是不是只要 17B 显存？ | 不是。未激活的专家权重仍要存储；跨 GPU 还要通信、负载均衡和 Token 调度。 |
| Meta 2026 年不是发了 Muse 吗？ | 是，但那是 Muse 品牌，不是 Llama。Llama 4（2025-04）是最后一代 Llama；Muse Glimmer 30B 反而回到了稠密架构。 |
