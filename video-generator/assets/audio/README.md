# 共享音频资产 · BGM 母版

本目录位于**功能层** `video-generator/assets/audio/`。按仓库约定，一级目录按功能
划分、二级按 agent 平台划分；**不属于任何单个平台包的素材放在功能层**，因此
BGM 母版既不放进 `qoder-video-generator/`，也不放进
`workbuddy-video-generator/`。

引用现状（避免误解）：

- `workbuddy-video-generator` 的流程把这段母版作为账号统一听感资产，默认引用它
  （脚本按三级解析定位，见下）。
- `qoder-video-generator` 的口径是「用户自备配乐，不替换、不代找、不用生成曲
  顶替」，**默认不引用本母版**；放在功能层只是不把它错误地归属给某个平台包，
  后续新增平台或用户需要时可直接复用。

> 平台包专有的音效（`workbuddy-video-generator/assets/audio/sfx/*.wav`）仍留在
> 各自包内，由该包的 `scripts/gen_sfx.py` 生成与维护，不随本目录共享。

## 文件

`VibeKnowledgeBGM_20min.m4a` —— 约 20 分钟、44.1 kHz 立体声 BGM 母版，
供各流程中的「按成片时长截取母版」步骤使用（参见
`workbuddy-video-generator/SKILL.md` §4.3 与 `docs/视频制作通用流程.md`）。

## 安装与引用

单独拷贝某个平台包安装时，若目标环境没有本目录，请用 `VIBE_BGM`
（部分旧脚本兼容 `VIBE_BGM_SRC`）指向自备音轨。各脚本按以下顺序解析：

1. 环境变量 `VIBE_BGM` / `VIBE_BGM_SRC`（绝对路径或相对当前工作目录）；
2. 技能包内 `assets/audio/<文件名>`（兼容「仓库根即技能包」的本地源仓布局）；
3. 功能层 `../assets/audio/<文件名>`（公开仓两级布局）。

三者都不存在时报错并提示，绝不静默使用临时合成音频顶替。
