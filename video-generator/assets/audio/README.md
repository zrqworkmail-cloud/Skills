# 自备音轨指引

**本仓不分发任何 BGM 音频文件。** 公开镜像曾随仓提供一段 20 分钟母版，
因其来源与授权范围无法确认，已移除。使用者须**自备音轨**并自行确认授权。

## 为什么自备

- 音乐的权利状态因人而异，公开仓无权替你判断能否分发、能否商用；
- 音频体积大（原母版 38.1 MB），与「产物不入库」的约定相冲突；
- 账号听感资产属于你的私有项目，不该进公开镜像。

## 怎么放

任选一种，脚本按同样的三级顺序解析：

1. **推荐：环境变量**（音轨可放在任意位置，不进仓库）
   ```bash
   export VIBE_BGM=/path/to/your-track.m4a      # 旧脚本也兼容 VIBE_BGM_SRC
   ```
2. 放到技能包内 `assets/audio/`（适合「仓库根即技能包」的私有源仓布局）；
3. 放到功能层 `video-generator/assets/audio/`（公开仓两级布局）。

三者都没有时，脚本会 `FileNotFoundError` 明确报错，**不会静默合成音频顶替**。
本目录的 `.gitignore` 已排除常见音频格式，防止把自备音轨误提交进仓库。

## 对音轨的要求

沿用流程里的判据（见 `workbuddy-video-generator/SKILL.md` §4.3 与
`docs/视频制作通用流程.md` §5 7.2），与音轨来源无关：

- 母版**远长于成片**（知识片 30s~4min，母版 20 分钟量级），直接按目标时长
  截取即可，不必做循环或延长剪辑；
- 截取用 `-t <成片时长>` 精确截断 + 尾部 1.2s `afade` + `volume=-1dB` 余量；
- 混流**禁 `-shortest`**；目标电平 mean ≈ −15 dB、峰值不触顶；
- 不要为每支片现合成新曲，保持账号听感一致。

使用权**。商用或公开投稿前请确认来源、作者、许可名称与适用范围，并在项目
文档登记。全仓许可分层见 `/LICENSE` 与 `/THIRD_PARTY_NOTICES.md`。
